# 指标体系设计

## 总体结构

城市宜居指数由 6 个一级指标组成：

| 一级指标 | 权重 |
|---|---:|
| 经济机会 | 25% |
| 生活成本 | 20% |
| 公共服务 | 15% |
| 环境质量 | 15% |
| 城市活力 | 15% |
| 气候舒适度 | 10% |

## 经济机会

用于衡量城市的经济发展水平和就业机会。

示例指标：

- 人均 GDP
- 平均工资
- 第三产业占比
- 新增企业数量

## 生活成本

用于衡量城市生活压力。

示例指标：

- 平均房价
- 平均租金
- 房价收入比
- 消费水平

## 公共服务

用于衡量城市生活便利程度。

示例指标：

- 医院数量
- 高校数量
- 地铁站数量
- 公交站数量
- 商场数量

## 环境质量

用于衡量城市自然环境和空气质量。

示例指标：

- AQI
- PM2.5
- 空气优良天数比例
- 公园数量
- 绿化覆盖率

## 城市活力

用于衡量城市人口流动和发展潜力。

示例指标：

- 人口增长率
- 年轻人口占比
- 新增企业数量
- 社会消费品零售总额

## 气候舒适度

用于衡量城市气候是否适合长期生活。

示例指标：

- 年平均气温
- 高温天数
- 低温天数
- 降水天数
- 湿度
