# CityInsight 2024 MVP 分析报告

## 1. 项目概述

CityInsight 是一个面向年轻人择城、就业和长期生活决策的城市宜居指数分析项目。项目通过整合城市经济发展、生活成本、公共服务和环境质量等多维数据，对长三角城市的宜居水平进行量化评估，并通过可视化图表展示不同城市的优势与短板。

本项目当前处于 MVP 阶段，即 Minimum Viable Product，最小可行产品阶段。本阶段的主要目标不是构建一个完全成熟的全国城市数据库，而是先验证完整的数据分析流程是否可行，包括数据来源追踪、指标表生成、数据质量检查、指数计算和基础可视化展示。

当前 MVP 版本首先选取长三角部分城市进行测试，包括上海、南京、苏州等城市。后续版本将继续扩展至长三角 8 个城市，并进一步补充租金、地铁站数量、公园数量、人口流动等指标。

---

## 2. 项目目标

本项目希望回答以下问题：

1. 在长三角主要城市中，哪些城市的综合宜居水平更高？
2. 不同城市在经济机会、生活成本、公共服务和环境质量方面分别有什么优势和短板？
3. 对年轻人而言，城市选择是否应只看经济机会，还是需要综合考虑房价、收入、公共服务和环境质量？
4. 能否通过公开数据构建一个可解释、可复现、可扩展的城市宜居评价体系？

项目最终目标是形成一个可扩展的数据分析平台，支持城市排名、城市详情、城市对比和个性化择城推荐等功能。

## 4. 数据处理流程

本项目的数据处理流程如下：

```text
data_source_tracking_2024.csv
        ↓
build_mvp_indicator_table.py
        ↓
city_indicators_2024_mvp.csv
        ↓
check_mvp_data.py
        ↓
calculate_livability_scores.py
        ↓
livability_scores_2024.csv
        ↓
create_basic_charts.py
        ↓
dashboard/figures
```

各文件和脚本的功能如下：

| 文件 / 脚本                          | 作用                  |
| -------------------------------- | ------------------- |
| `data_source_tracking_2024.csv`  | 原始数据来源追踪表           |
| `city_indicators_2024_mvp.csv`   | 由来源表自动生成的城市指标宽表     |
| `build_mvp_indicator_table.py`   | 将来源追踪表转换为指标表        |
| `check_mvp_data.py`              | 检查缺失值、重复行、城市匹配和数值范围 |
| `calculate_livability_scores.py` | 计算各维度得分和综合宜居指数      |
| `livability_scores_2024.csv`     | 输出最终得分和排名           |
| `create_basic_charts.py`         | 生成基础可视化图表           |

这种设计避免了直接手动维护最终指标表，使数据来源和计算结果之间保持可追踪、可复现。

## 5. 指标体系设计

当前 MVP 版本将城市宜居指数分为四个一级维度：

| 一级维度 |  权重 | 含义                     |
| ---- | --: | ---------------------- |
| 经济机会 | 35% | 衡量城市经济发展水平、产业结构和就业收入条件 |
| 生活成本 | 30% | 衡量房价、租金和购房压力           |
| 公共服务 | 20% | 衡量医疗、教育和交通等公共资源        |
| 环境质量 | 15% | 衡量空气质量和生态环境水平          |

当前未加入“城市活力”和“气候舒适度”两个维度，主要原因是 MVP 阶段相关数据尚未完全整理。后续版本将继续扩展。

## 6. 指标字段说明

### 6.1 经济机会指标

| 字段名                       | 含义              | 指标方向 |
| ------------------------- | --------------- | ---- |
| `gdp_per_capita`          | 人均 GDP          | 正向   |
| `avg_salary_non_private`  | 城镇非私营单位就业人员平均工资 | 正向   |
| `avg_salary_private`      | 城镇私营单位就业人员平均工资  | 正向   |
| `tertiary_industry_ratio` | 第三产业增加值占 GDP 比重 | 正向   |

经济机会维度主要反映一个城市的发展水平、产业结构和收入条件。其中，人均 GDP 衡量宏观经济发展水平，工资指标衡量就业收入水平，第三产业占比则反映城市服务业和现代产业发展程度。

---

### 6.2 生活成本指标

| 字段名                                    | 含义                | 指标方向 |
| -------------------------------------- | ----------------- | ---- |
| `house_price`                          | 平均房价              | 负向   |
| `avg_rent`                             | 平均租金              | 负向   |
| `house_price_income_ratio_non_private` | 基于非私营单位工资计算的房价收入比 | 负向   |
| `house_price_income_ratio_private`     | 基于私营单位工资计算的房价收入比  | 负向   |

生活成本维度主要衡量居住压力。由于房价对年轻人择城和长期定居影响较大，本项目将房价收入比作为重要衍生指标。

房价收入比计算公式为：

```text
房价收入比 = 平均房价 × 90㎡ / 年平均工资
```

其中，90㎡被设定为标准住房面积。

由于非私营单位和私营单位工资差异较大，本项目分别计算两个房价收入比：

```text
house_price_income_ratio_non_private = house_price × 90 / avg_salary_non_private
house_price_income_ratio_private = house_price × 90 / avg_salary_private
```

最终结果保留一位小数。

---

### 6.3 公共服务指标

| 字段名                   | 含义       | 指标方向 |
| --------------------- | -------- | ---- |
| `hospital_count`      | 医院数量     | 正向   |
| `university_count`    | 普通高等学校数量 | 正向   |
| `metro_station_count` | 地铁站数量    | 正向   |

公共服务维度衡量城市在医疗、教育和交通方面的资源供给能力。当前 MVP 版本使用绝对数量进行初步比较。后续版本将进一步改进为按人口规模归一化，例如每百万人医院数量、每百万人高校数量等。

---

### 6.4 环境质量指标

| 字段名                   | 含义         | 指标方向 |
| --------------------- | ---------- | ---- |
| `pm25`                | PM2.5 年均浓度 | 负向   |
| `good_air_days_ratio` | 空气质量优良天数比例 | 正向   |
| `park_count`          | 公园数量       | 正向   |

环境质量维度主要反映空气质量和城市生态条件。PM2.5 数值越低，空气质量越好；空气质量优良天数比例越高，说明全年空气质量稳定性更好。

## 7. 标准化方法

由于各指标的量纲不同，例如人均 GDP 的单位是元/人，房价的单位是元/平方米，PM2.5 的单位是 μg/m³，因此需要将所有指标统一转换为 0–100 分。

### 7.1 正向指标标准化

对于数值越高越好的指标，采用以下公式：

```text
score = (x - min) / (max - min) × 100
```

适用指标包括：

* 人均 GDP
* 平均工资
* 第三产业占比
* 医院数量
* 高校数量
* 地铁站数量
* 空气质量优良天数比例
* 公园数量

---

### 7.2 负向指标标准化

对于数值越低越好的指标，采用以下公式：

```text
score = (max - x) / (max - min) × 100
```

适用指标包括：

* 平均房价
* 平均租金
* 房价收入比
* PM2.5 年均浓度

---

### 7.3 相同值处理

如果某个指标在所有城市中的数值相同，则无法进行 Min-Max 拉伸。此时统一给该指标 50 分，表示该指标在当前样本中不产生区分度。

---

## 8. 综合得分计算

当前 MVP 版本综合宜居指数由四个一级维度加权得到：

```text
total_score =
economy_score × 0.35
+ cost_score × 0.30
+ service_score × 0.20
+ environment_score × 0.15
```

其中：

| 维度   |  权重 |
| ---- | --: |
| 经济机会 | 35% |
| 生活成本 | 30% |
| 公共服务 | 20% |
| 环境质量 | 15% |

当前权重采用人工赋权方式。其基本思路是：年轻人择城时通常较重视经济机会和生活成本，因此经济机会和生活成本权重较高；公共服务和环境质量同样重要，但在 MVP 阶段权重略低。

后续版本可以尝试使用层次分析法 AHP 或熵权法进行更系统的权重设计。

## 11. 初步分析

### 11.1 上海：高经济机会，高公共服务，高生活成本

上海在人均 GDP、工资水平、公共服务资源等方面具有明显优势，因此在经济机会和公共服务维度中表现突出。

但上海房价较高，导致生活成本得分较低。这说明上海更适合重视职业发展、产业机会和公共资源的用户，但对于购房压力敏感的年轻人来说，长期定居成本较高。

---

### 11.2 南京：综合表现相对均衡

南京在经济发展、教育医疗资源和生活成本之间具有一定平衡性。相比上海，南京的房价压力较低；相比苏州，南京的公共服务和城市功能更强。

因此，南京在当前测试数据中表现为相对均衡型城市。

---

### 11.3 苏州：生活成本优势较明显

苏州在房价压力方面相对低于上海，因此生活成本维度得分较高。同时，苏州经济总量和制造业基础较强，但由于第三产业占比相对低于上海、南京，在经济机会维度上的标准化得分可能受到影响。

从当前结果看，苏州更适合关注生活成本、产业就业和城市性价比的用户。

---

## 12. 当前局限性

当前 MVP 版本仍存在以下局限：

### 12.1 样本城市数量较少

当前可视化结果主要基于上海、南京、苏州三个城市。由于样本量较小，Min-Max 标准化会放大城市之间的差异，使得 0 分和 100 分频繁出现。

后续补齐 8 个城市后，分数分布会更加稳定。

---

### 12.2 部分指标仍然缺失

当前部分指标仍未完全整理，例如：

* 平均租金
* 地铁站数量
* 公园数量
* 医院数量
* 高校数量
* 城市活力指标
* 气候舒适度指标

这些缺失会影响部分维度得分的完整性。

---

### 12.3 公共服务指标尚未人口归一化

当前公共服务指标使用的是绝对数量，例如医院数量和高校数量。这种方法会对人口规模较大的城市更有利。

后续版本可以改为：

```text
每百万人医院数量
每百万人高校数量
每百万人地铁站数量
```

这样能更公平地衡量居民实际享受到的公共服务资源。

---

### 12.4 房价数据来自第三方平台

房价数据并非官方统计公报中的统一指标，而是来自第三方平台的公开房价数据。不同平台可能存在统计口径差异，例如新房、二手房、挂牌价和成交价之间可能不同。

当前 MVP 阶段采用统一平台和统一年份数据，以尽量保证横向可比性。

---

### 12.5 权重采用人工设定

当前四个一级维度的权重由项目人工设定，虽然符合年轻人择城的基本逻辑，但仍具有主观性。

后续可以使用以下方法优化权重：

1. AHP 层次分析法；
2. 熵权法；
3. 用户偏好权重；
4. 多版本权重对比。

---

## 15. 总结

CityInsight MVP 版本已经初步验证了城市宜居指数项目的核心流程。通过数据来源追踪、指标表生成、数据检查、标准化评分和图表展示，项目已经从单纯的想法转化为一个可运行、可复现、可扩展的数据分析作品。

当前结果表明，城市宜居性不是单一经济指标可以解释的。上海在经济机会和公共服务方面具有优势，但生活成本压力较高；苏州在生活成本方面更有优势；南京则表现出一定的综合平衡性。

后续随着数据补齐和模型优化，该项目可以进一步发展为一个面向年轻人择城决策的完整数据分析平台。
