# CityInsight 项目定义

为年轻人提供基于历史公开数据的城市比较工具，帮助理解经济、住房、服务与环境的权衡。项目不预测个人收入，也不直接代替实地择城决定。

## 已交付的研究预览

- 上海、苏州、南京、杭州、宁波、无锡、合肥、常州八城数据库骨架及真实核心指标。
- 来源追踪 → 全城市指标宽表 → 阻断式校验 → 可比组评分 → 偏好分析 → 图表/报告 → 静态交互看板。
- 城市原始指标对比、四维画像、偏好权重、搜索排序、CSV下载、来源追溯、覆盖率与待补状态。
- Python回归测试、浏览器检查脚本与GitHub Actions流程。

实际可综合排名的城市仍为三城，其余五城等待住房等数据。城市活力、气候和人口归一后的公共服务属于后续模型研究，不应提前宣称已实现。

## 下一阶段验收

1. 统一2024年12月二手房价和租金采样口径，记录城市区域、户型面积、样本范围、来源时点，复核现有三城房价。
2. 补医院统一分类、地铁站换乘去重、公园年末存量；再按常住人口归一，避免大小城市的资源总量偏差。
3. 八城四维共同指标达到最低条件后生成完整暂定排名；引入更高覆盖率要求与口径审批，减少因新增城市删减共同指标。
4. 在完整数据上比较独立的生活成本指标、权重方法和基准区间，降低重复指标影响。
5. 若需要在线服务，再引入API、PostgreSQL导入与部署。当前SQL仅提供初始化设计，不代表已部署数据库。
