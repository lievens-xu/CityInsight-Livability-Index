# CityInsight 项目定义

为年轻人提供基于历史公开数据的城市比较工具，帮助理解经济、住房、服务与环境的权衡。

## 已交付范围

- 上海、苏州、南京、杭州、宁波、无锡、合肥、常州、广州、深圳，共十城2024年12项原始指标，120条完整已核对来源记录。
- 来源追踪 → 全城市宽表 → 完整性校验 → 四维评分 → 偏好与敏感性分析 → 图表/报告 → 静态交互看板。
- 搜索排序、两城原始值和画像对比、四维权重、CSV下载、精确出处和口径查询，支持离线使用。
- Python回归测试、浏览器检查、GitHub Actions和生成文件复现检查。

新增或更新发布数据必须满足全部原始指标完整、来源verified且具有复核日期。模型保留缺失状态机制以支持研究测试，但发布流程会阻止不完整数据。

## 后续模型研究

1. 加入常住人口、床位等容量指标，比较人均资源，减少城市规模影响。
2. 引入家庭可支配收入和更独立的成本指标，降低房价与工资的重复影响。
3. 研究通勤、气候、活力及固定基准区间，保留对不同统计范围的说明。
4. 根据需求接入API、数据库导入和在线部署。当前SQL提供初始化设计，实际数据库运行尚未验证。
