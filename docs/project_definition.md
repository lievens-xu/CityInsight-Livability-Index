# 项目定义

## 项目名称

CityInsight：中国城市宜居指数分析平台

## 项目定位

本项目是一个面向年轻人择城、就业和长期生活决策的数据分析平台。项目通过整合城市经济、生活成本、公共服务、环境质量、城市活力和气候舒适度等多维数据，构建城市宜居指数，并通过可视化方式展示不同城市的优势和短板。

## 目标用户

1. 应届毕业生
2. 准备换城市工作的年轻职场人
3. 对城市发展和数据分析感兴趣的用户

## 核心问题

1. 哪些城市综合宜居程度更高？
2. 不同城市的优势和短板是什么？
3. 对年轻人来说，哪些城市更适合就业和生活？

## MVP 范围

本项目第一版以长三角 8 个城市为研究对象：

- 上海
- 苏州
- 南京
- 杭州
- 宁波
- 无锡
- 合肥
- 常州

## MVP 功能

1. 城市宜居指数排名
2. 城市详情页
3. 城市对比
4. 可视化分析
5. 个性化城市推荐
