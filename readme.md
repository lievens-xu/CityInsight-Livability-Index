## 1. 项目简介

CityInsight 是一个面向年轻人择城、就业和生活决策的城市数据分析平台。项目通过整合城市经济、生活成本、公共服务、环境质量、城市活力和气候舒适度等多维指标，构建城市宜居指数，并提供城市排名、城市详情、城市对比和个性化推荐功能。

本项目首先以长三角 8 个代表性城市作为 MVP 版本，包括上海、苏州、南京、杭州、宁波、无锡、合肥和常州。后续可扩展至全国主要城市。

## 2. 项目目标

本项目希望回答以下问题：

1. 哪些城市综合宜居程度更高？
2. 不同城市在经济机会、生活成本、环境质量和公共服务方面各有什么优势？
3. 对应届毕业生和年轻职场人来说，哪些城市更适合长期工作和生活？

## 4. 指标体系

本项目的宜居指数由 6 个一级指标构成：

| 一级指标 | 权重 | 示例指标 |
|---|---:|---|
| 经济机会 | 25% | 人均 GDP、平均工资、第三产业占比、新增企业数量 |
| 生活成本 | 20% | 平均房价、平均租金、房价收入比、消费水平 |
| 公共服务 | 15% | 医院数量、高校数量、地铁站数量、公交站数量 |
| 环境质量 | 15% | AQI、PM2.5、空气优良天数、公园数量 |
| 城市活力 | 15% | 人口增长率、年轻人口占比、新增企业数量 |
| 气候舒适度 | 10% | 年平均气温、高温天数、低温天数、降水天数 |


## 5. 核心功能

### 5.1 城市宜居排名

展示长三角 8 城市的综合宜居指数排名。

### 5.2 城市详情页

展示单个城市的总分、分项得分和关键指标。

### 5.3 城市对比

支持两个城市之间的横向对比，例如苏州 vs 杭州。

### 5.4 可视化分析

使用图表展示城市排名、分项得分、房价收入比、经济机会与生活成本关系等。

### 5.5 个性化推荐

根据用户偏好调整指标权重，推荐更适合用户需求的城市。
